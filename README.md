# Shorts Shadowban

A lightweight, zero-dependency browser extension that adds a 🚫 button to YouTube Shorts. Block a channel once and its Shorts are automatically skipped from then on.

## Download and setup

Visit the **[Shorts Shadowban website](https://hamgram77.github.io/shorts-shadowban/)** for the extension download, demo, browser-specific installation instructions, and the no-install Safari bookmarklet.

The extension supports Chromium browsers directly. Safari users can convert the Manifest V3 extension with Xcode or use the included bookmarklet on iPhone and iPad.

## Privacy

Your blocklist is stored locally in your browser. Shorts Shadowban has no analytics, accounts, servers, third-party code, or network requests.
