Setup & use

Pick your platform.

01

Google Chrome

Load and activate

Windows, macOS, Linux, or ChromeOS
  1. 1
    Download and extract the ZIP

    Use the download button above. Open shorts-shadowban.zip and extract it somewhere permanent—do not load the extension from inside the ZIP.

  2. 2
    Open Chrome’s extension manager

    Type chrome://extensions in the address bar and press Enter.

  3. 3
    Turn on Developer mode

    Enable the switch in the upper-right corner. The “Load unpacked” button will appear.

  4. 4
    Select the correct folder

    Click “Load unpacked,” open the extracted download, and select extension/. Confirm that manifest.json is directly inside the folder you select.

  5. 5
    Pin Shorts Shadowban

    Click Chrome’s puzzle-piece icon, then the pin beside Shorts Shadowban. The toolbar popup lets you unblock channels later.

  6. 6
    Allow YouTube and test it

    Open youtube.com/shorts. If Chrome asks for site access, choose Allow. The 🚫 button should appear beside Like and Share automatically.

Installed correctly? The extension card says version 1.0.2 or later, its popup opens, and the Shorts action column contains 🚫.

02

Brave Browser

Load and activate

Desktop Brave
  1. 1
    Download and extract

    Download the ZIP, extract it, and locate the inner extension/ folder containing manifest.json.

  2. 2
    Open Brave extensions

    Type brave://extensions in the address bar and press Enter.

  3. 3
    Enable Developer mode

    Turn on Developer mode in the upper-right corner.

  4. 4
    Load the extension

    Choose “Load unpacked” and select the extracted extension/ folder, not the repository root or ZIP file.

  5. 5
    Pin and allow access

    Pin Shorts Shadowban from Brave’s Extensions menu. Open its Details page and verify that access to youtube.com is allowed.

  6. 6
    Open Shorts

    Visit youtube.com/shorts. If Brave Shields blocks page behavior, leave Shields enabled first; only test with Shields lowered if the 🚫 button does not appear.

Updating later: Replace the extracted files, then return to brave://extensions and click Reload on the extension card.

03

Microsoft Edge

Sideload and activate

Desktop Edge
  1. 1
    Download and extract

    Download the ZIP and extract it. Find extension/manifest.json before continuing.

  2. 2
    Open Edge extensions

    Type edge://extensions in the address bar and press Enter.

  3. 3
    Enable Developer mode

    Turn on Developer mode using the switch in the left sidebar.

  4. 4
    Load unpacked

    Click “Load unpacked,” select the extracted extension/ directory, and choose Select Folder.

  5. 5
    Show it on the toolbar

    Open Edge’s Extensions menu and select the eye icon beside Shorts Shadowban so its unblock menu stays accessible.

  6. 6
    Verify YouTube access

    Open the extension’s Details page, confirm site access includes YouTube, then visit youtube.com/shorts.

Expected result: 🚫 appears automatically in the active Short’s Like/Share column and the toolbar popup lists blocked handles.

04

Safari on macOS

Quick test or permanent app

Safari 17 or later recommended
  1. 1
    Download and extract

    Download the ZIP and extract the included extension/ folder.

  2. 2
    Quick test: enable Developer features

    In Safari choose Settings → Advanced and enable “Show features for web developers.” Open Settings → Developer and turn on “Allow unsigned extensions.”

  3. 3
    Quick test: add the folder

    In Safari Settings → Developer choose “Add Temporary Extension…” and select extension/. Temporary extensions are removed when Safari quits or after 24 hours.

  4. 4
    Permanent route: package with Xcode

    Install Xcode. In Terminal run xcrun safari-web-extension-packager /path/to/extension. Choose Swift when prompted; the packager opens a generated Xcode project.

  5. 5
    Build the macOS app

    In Xcode select the macOS app scheme, choose your Mac as the destination, configure a Signing Team if requested, then press Run.

  6. 6
    Enable and authorize it

    Open Safari → Settings → Extensions, check Shorts Shadowban, and set its website access for youtube.com to Allow.

  7. 7
    Test Shorts

    Open youtube.com/shorts. The 🚫 control should appear beside Like and Share. Use the Safari toolbar extension button to manage blocked channels.

Unsigned build note: Safari’s “Allow unsigned extensions” setting resets when Safari quits. A signed Xcode build avoids the temporary-development workflow.

05

iPhone · iPad Safari

Activate the bookmarklet

No app download required
  1. 1
    Copy the current code

    Scroll to the green “Zero-download mode” section and tap “Copy Bookmarklet Code.” Recopy it whenever the bookmarklet is updated.

  2. 2
    Create a temporary bookmark

    In Safari, tap Share → Add Bookmark. Save this page as any bookmark; its current address will be replaced next.

  3. 3
    Edit the bookmark

    Open Safari’s bookmarks, tap Edit, choose the bookmark, rename it “🚫 Shadowban Shorts,” delete its address, and paste the copied code. It must begin with javascript:.

  4. 4
    Stay in Safari

    Open youtube.com directly in Safari. Do not switch to the YouTube app—bookmarklets cannot run inside another app.

  5. 5
    Activate once per loaded tab

    While on YouTube, open the “🚫 Shadowban Shorts” bookmark. Dismiss the activation message, then enter Shorts in the same tab.

  6. 6
    Use the action button

    The 🚫 control appears beside Like and Share. Tap it to save that creator locally and advance to the next Short.

  7. 7
    Reactivate after reload

    Safari security prevents bookmarklets from auto-running after a page reload, closed tab, or new tab. Open the bookmark once again; normal movement within that YouTube tab remains active.

If nothing happens: Edit the bookmark and confirm its address starts with javascript:, use Safari rather than the YouTube app, and make sure Private Browsing is off so the blocklist can be stored.
