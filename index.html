Setup & use

Pick your platform.

01

Google Chrome

Load and activate

Windows, macOS, Linux, or ChromeOS
  1. 1
    Download the archive

    Return to the top of this page and choose “Download Extension (.zip).” Save shorts-shadowban.zip somewhere you can find again.

  2. 2
    Extract it permanently

    Right-click the ZIP and choose Extract All. Move the extracted folder somewhere permanent; Chrome loses unpacked extensions if their files are moved or deleted.

  3. 3
    Find the manifest folder

    Open the extracted download. The correct folder is extension/, with manifest.json, content.js, and popup.html directly inside it.

  4. 4
    Open extension management

    Type chrome://extensions into Chrome’s address bar and press Enter. Turn on Developer mode in the upper-right corner.

  5. 5
    Load unpacked

    Click “Load unpacked,” select the extension/ folder, and click Select Folder. A Shorts Shadowban card should appear without errors.

  1. 1
    Pin the toolbar button

    Click Chrome’s puzzle-piece icon and then the pin beside Shorts Shadowban. Click the new toolbar icon once to confirm the unblock popup opens.

  2. 2
    Confirm site access

    On chrome://extensions, open Shorts Shadowban → Details. Under Site access, ensure YouTube is allowed. The manifest requests access only to YouTube pages.

  3. 3
    Open Shorts

    Visit https://www.youtube.com/shorts. The extension also activates if YouTube was already open when it was installed.

  4. 4
    Locate the control

    Wait for the first Short to finish loading. 🚫 appears in the right-side vertical action column beside Like, Comments, Share, and Remix.

  1. 1
    Test a channel

    Tap 🚫 on a Short. The creator’s @handle should be saved and the feed should immediately advance.

  2. 2
    Check the popup

    Open the toolbar popup. The blocked handle should be listed; choose Unblock to restore that creator.

  3. 3
    If the button is missing

    Return to chrome://extensions, confirm the extension is enabled, click Reload on its card, and check its Details page for YouTube site access.

  4. 4
    Update the extension

    Replace the old extracted files with the latest download, then click Reload on the extension card. You do not need to remove your saved blocklist.

Success check: Version 1.0.2 or later is enabled, the popup opens, 🚫 appears in Shorts, and blocked handles show in the popup.

02

Brave Browser

Load and activate

Desktop Brave
  1. 1
    Download and extract

    Download shorts-shadowban.zip, extract it to a permanent location, and open the resulting folder.

  2. 2
    Verify the source folder

    Find extension/. It is correct when manifest.json is immediately visible inside it.

  3. 3
    Open Brave extensions

    Enter brave://extensions in the address bar and enable Developer mode in the upper-right corner.

  4. 4
    Load unpacked

    Click “Load unpacked,” choose extension/, and confirm. Do not choose the outer download folder or the ZIP itself.

  1. 1
    Pin the extension

    Open Brave’s Extensions menu and pin Shorts Shadowban so the unblock popup remains easy to reach.

  2. 2
    Allow YouTube

    Open the extension’s Details page and confirm site access is enabled for youtube.com.

  3. 3
    Visit Shorts

    Open https://www.youtube.com/shorts and wait for the active video and its action buttons to load.

  4. 4
    Find 🚫

    The new circular control appears in the same right-side column as Like, Comments, Share, and Remix.

  1. 1
    Block and verify

    Tap 🚫, confirm the next Short opens, then check the extension popup for the creator’s handle.

  2. 2
    Check Brave Shields

    Keep Shields enabled normally. If the button never appears, temporarily lower Shields for YouTube to determine whether a custom Shields setting is blocking page scripts.

  3. 3
    Reload the package

    On brave://extensions, click Reload on the extension card after updating its files or if the service worker reports an error.

  4. 4
    Restore a creator

    Open the pinned toolbar popup and choose Unblock beside the handle. The change is stored locally and takes effect immediately.

Success check: The popup opens, YouTube access is enabled, and tapping 🚫 advances the feed and records the handle.

03

Microsoft Edge

Sideload and activate

Desktop Edge
  1. 1
    Download and extract

    Save the ZIP, choose Extract All, and keep the extracted files in a permanent folder.

  2. 2
    Locate manifest.json

    Open extension/ and confirm the manifest sits directly inside that directory.

  3. 3
    Open Edge extensions

    Type edge://extensions in the address bar. Enable Developer mode using the switch in the left sidebar.

  4. 4
    Sideload the folder

    Choose “Load unpacked,” select extension/, and click Select Folder. Edge should display a Shorts Shadowban extension card.

  1. 1
    Show the toolbar icon

    Open Edge’s Extensions menu and select the eye icon beside Shorts Shadowban.

  2. 2
    Review permissions

    Open Details and confirm the extension is enabled and allowed to read and change data on YouTube.

  3. 3
    Start YouTube Shorts

    Visit https://www.youtube.com/shorts. Existing YouTube tabs should receive the extension automatically.

  4. 4
    Confirm placement

    Look for 🚫 in the vertical control stack beside Like, Comments, Share, and Remix.

  1. 1
    Run a blocking test

    Tap 🚫 on a test creator. Edge should immediately advance and the handle should appear in the toolbar popup.

  2. 2
    If 🚫 is absent

    Check that the selected unpacked directory contains manifest.json, then click Reload on edge://extensions.

  3. 3
    Inspect reported errors

    On the extension card, choose Errors if Edge shows one. A clean installation should show no manifest or service-worker errors.

  4. 4
    Update or unblock

    Reload after replacing extension files. Use the toolbar popup’s Unblock button to remove a saved handle.

Success check: Edge shows no extension errors, 🚫 is visible, and the popup accurately reflects the local blocklist.

04

Safari on macOS

Quick test or permanent app

Safari 17 or later recommended
  1. 1
    Download and extract

    Download the ZIP and extract extension/ so Safari can read its manifest and scripts.

  2. 2
    Show developer features

    Open Safari → Settings → Advanced and enable “Show features for web developers.” A Developer tab appears in Safari Settings.

  3. 3
    Allow unsigned extensions

    Open Settings → Developer and enable “Allow unsigned extensions.” Authenticate with your Mac password if Safari asks.

  4. 4
    Add a temporary extension

    Choose “Add Temporary Extension…” and select extension/. Safari adds Shorts Shadowban to its Extensions settings.

  5. 5
    Understand the limit

    This quick test is removed when Safari quits or after 24 hours. Repeat these steps or use the Permanent app sub-tab for lasting installation.

  1. 1
    Install Xcode

    Install and open the current Xcode release from Apple. Allow it to finish installing required components.

  2. 2
    Run Apple’s packager

    Open Terminal and run xcrun safari-web-extension-packager /full/path/to/extension. The older converter command has been replaced by this packager.

  3. 3
    Answer the prompts

    Choose Swift if asked, enable the macOS target, choose a project location, and let the tool open the generated Xcode project.

  4. 4
    Configure signing

    Select the project and its macOS app target. Under Signing & Capabilities choose your Team and use a unique bundle identifier if Xcode reports a conflict.

  5. 5
    Build and run

    Select the macOS app scheme and your Mac as the destination, then press Run. Launching the containing app installs the web extension into Safari.

  1. 1
    Enable the extension

    Open Safari → Settings → Extensions and check Shorts Shadowban in the left-hand list.

  2. 2
    Allow YouTube

    Set website access for youtube.com to Allow or Always Allow. If Safari uses Profiles, enable the extension for the active profile too.

  3. 3
    Open and test Shorts

    Visit https://www.youtube.com/shorts. 🚫 should appear beside Like and Share after the active Short loads.

  4. 4
    If it is missing

    Confirm the containing app was run at least once, recheck Safari’s Extensions and profile settings, then build the Xcode project again.

  5. 5
    Manage the blocklist

    Use the Safari toolbar extension button to open the popup and unblock saved handles.

Unsigned-build note: “Allow unsigned extensions” resets when Safari quits. A properly signed app installation avoids that development-only reset.

05

iPhone · iPad Safari

Activate the bookmarklet

No app download required
  1. 1
    Use Safari for setup

    Open this website in Safari on the iPhone or iPad. The bookmarklet cannot be installed or run from inside the YouTube app, Chrome for iOS, or an in-app browser.

  2. 2
    Copy the latest code

    In the green Zero-download section, tap “Copy Bookmarklet Code.” The copied address begins with javascript: followed by encoded code.

  3. 3
    Create a placeholder bookmark

    Tap Safari’s Share button, choose Add Bookmark, and save this page. The page address is temporary and will be replaced.

  4. 4
    Open bookmark editing

    Tap Safari’s bookmarks icon, locate the new bookmark, tap Edit, and select it.

  5. 5
    Replace its name and address

    Name it “🚫 Shadowban Shorts.” Delete the entire existing URL, paste the copied bookmarklet address, and tap Done. Confirm the saved address still starts with javascript:.

  1. 1
    Open YouTube in Safari

    Type youtube.com into Safari’s address bar. If iOS offers to open the YouTube app, stay in Safari.

  2. 2
    Run the bookmark once

    While the YouTube website is visible, open Safari’s bookmarks and tap “🚫 Shadowban Shorts.” A message confirms that Shorts Shadowban is active.

  3. 3
    Enter Shorts in the same tab

    Dismiss the message and tap Shorts on YouTube. Do not open a new tab. The script watches YouTube’s internal navigation in the currently activated tab.

  4. 4
    Locate 🚫

    After the active video loads, 🚫 appears in the same action column as Like and Share. If YouTube’s layout prevents that placement, it appears as a floating button near the lower-right corner.

  5. 5
    Know when to reactivate

    Run the bookmark again after reloading YouTube, closing the tab, opening a new tab, or reopening Safari. iOS prevents bookmarklets from auto-running on fresh page loads.

  1. 1
    Shadowban a creator

    Tap 🚫. The script reads the visible creator’s @handle, saves it in YouTube’s local Safari storage, and advances to the next Short.

  2. 2
    Confirm automatic skipping

    If the same handle appears later in the activated tab, the script advances automatically.

  3. 3
    If the bookmark does nothing

    Edit it and confirm the address begins exactly with javascript:. Recopy the current code from this page if the saved bookmark uses an older version.

  4. 4
    If 🚫 does not appear

    Confirm you are on youtube.com in Safari, not the YouTube app. Run the bookmark while YouTube is open, dismiss its activation message, then enter Shorts in that same tab.

  5. 5
    If saving fails

    Turn off Private Browsing for this tab and allow website data. Safari needs local storage to remember blocked handles.

  6. 6
    Clear the bookmarklet blocklist

    Open Safari Settings → Apps → Safari → Advanced → Website Data, find YouTube, and remove its website data. This also signs the website out and clears other YouTube site preferences.

Platform limit: A bookmarklet cannot launch itself on a new or reloaded Safari page. Automatic fresh-page activation requires a packaged iOS Safari Web Extension app.
