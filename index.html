Setup & use

Pick your platform.

01

Chrome · Brave · Edge

Install the extension

  1. 1
    Download and unzip

    Click “Download Extension (.zip)” above, then extract shorts-shadowban.zip.

  2. 2
    Open extensions

    Visit chrome://extensions, brave://extensions, or edge://extensions.

  3. 3
    Enable Developer mode

    Turn on the Developer mode switch in the top-right corner.

  4. 4
    Load the folder

    Choose “Load unpacked” and select the extracted extension/ folder—the one containing manifest.json.

02

Mac Safari

Convert with Xcode

  1. 1
    Download and unzip

    Extract the ZIP and locate the included extension/ folder.

  2. 2
    Convert the web extension

    In Terminal run xcrun safari-web-extension-converter /path/to/extension. Xcode creates a Safari app project.

  3. 3
    Build and enable

    Run the project in Xcode, then open Safari → Settings → Extensions and enable Shorts Shadowban.

  4. 4
    Allow YouTube access

    When Safari asks, allow the extension on youtube.com.

03

iPad · iPhone Safari

Use the bookmarklet

  1. 1
    Create any bookmark

    In Safari, bookmark this page. Open Bookmarks, tap Edit, then select the new bookmark.

  2. 2
    Copy the code

    Tap “Copy Bookmarklet Code” above and replace the bookmark’s address with the copied javascript: code.

  3. 3
    Name and save it

    Call it “🚫 Shadowban Shorts,” save it, then visit youtube.com/shorts in Safari.

  4. 4
    Activate each session

    Open the bookmark from the bookmarks menu after loading or refreshing YouTube.
